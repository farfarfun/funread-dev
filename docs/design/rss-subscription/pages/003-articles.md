# 文章列表与正文

## 文章列表（`/web/rss/:subId`）

```
┌─────────────────────────────┐
│ ‹ Hacker News    [全读][刷新]│
├─────────────────────────────┤
│ 更新 热血 校园 推理 机战 ... │  ← 横滚，不换行
├─────────────────────────────┤
│ 这个源没有正文规则，文章会    │  ← has_content=false 时
│ 直接在浏览器里打开。          │
├─────────────────────────────┤
│ Whistle: Speech to Text  ┌──┐│
│ 摘要两行…                │图││ ☆
│ 2026-10-09               └──┘│
├─────────────────────────────┤
│ 已读的标题整条压暗 opacity.55 │
├─────────────────────────────┤
│         [加载更多]           │
│      或「没有更多了」         │
└─────────────────────────────┘
```

分类条横向滚动而不是换行：实测有源带 16 个分类，换行会堆出三四行把列表挤下去。

**已读状态用整条压暗（`opacity: .55`）而不是一个小标记。** 这是列表里最需要一眼
分清的状态，扫视时靠明暗比靠找标记快得多。

收藏星单独占 44px 的点击区，并 `@click.stop` —— 它和整条卡片的点击区挨在一起，
不拦住事件就会既收藏又跳转。

## 文章正文（`/web/rss/:subId/article`）

```
┌─────────────────────────────┐
│ ‹ 标题        [☆][设置][↗]  │
├─────────────────────────────┤
│                             │
│ Whistle: Speech to Text     │
│ 2026-10-09                  │
│                             │
│ 正文 HTML（已消毒）          │
│ 图片 max-width:100%          │
│ 表格可横滚                   │
│ 链接 target=_blank + noopener│
│                             │
└─────────────────────────────┘
```

和小说正文不同，这里**保留顶栏**：订阅文章短，不需要沉浸式，而「在浏览器里打开」
这个出口必须随时可点（源站排版经常比我们好）。

共用小说那套阅读设置（字号/行距/配色），所以 `[设置]` 按钮开的是同一个
`ReaderSettingsSheet`。

**打开即已读** —— 订阅阅读的常规语义，不必再点一下。

正文为空时给一句「这篇文章没有可显示的正文」加一个外跳链接，而不是一片空白。
