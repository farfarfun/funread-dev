# 书籍详情与正文

## 详情（`/web/book/:bookKey`）

从上到下：封面区 → 主操作 → 简介（折叠）→ 离线下载 → 目录。

```
┌─────────────────────────────┐
│ ‹ 剑来                 [换源]│
├─────────────────────────────┤
│ ┌────┐ 剑来                  │
│ │封面│ 烽火戏诸侯            │
│ │    │ 玄幻  420万字          │
│ └────┘ 来源：甲源            │
├─────────────────────────────┤
│ [    续读第 7 章    ] [移出] │
├─────────────────────────────┤
│ 少年抱剑……（3 行后折叠）  展开│
├─────────────────────────────┤
│ 离线下载        已缓存 42 章 │
│ ▓▓▓▓▓▓░░░░░░░░░░ 38%        │  下载中才显示
│ [下载未缓存章节] [清空缓存]  │
├─────────────────────────────┤
│ 目录 (1203)            倒序  │
│ [🔍 在目录里找章节        ]  │
│ 第一章 ……            已缓存  │  虚拟滚动区
│ 第二章 ……                    │
└─────────────────────────────┘
```

主按钮的文案跟着状态变：不在架上是「加入书架」，在架上有进度是「续读第 N 章」，
在架上无进度是「开始阅读」。用户不需要先判断自己处在哪个状态。

目录区高度固定 `min(60dvh, 520px)` —— 虚拟滚动需要一个可滚容器，没有固定高度就
没有「可见窗口」这个概念。

## 正文（`/web/read/:bookKey`）

沉浸式。整页 `position: fixed; inset: 0`，内部自己滚。

```
┌─────────────────────────────┐
│                             │
│        第一章 惊蛰          │  居中标题
│                             │
│   　　少年抱剑，站在……      │  首行缩进 2em
│   　　两端对齐               │  text-align: justify
│                             │
│   [上一章]  3 / 1203  [下一章]│
└─────────────────────────────┘
      ↑ 点中部唤出工具栏
┌─────────────────────────────┐
│  ‹   目录   设置   换源   ›  │  工具栏（滑入）
└─────────────────────────────┘
```

**手势分区**：屏宽左右各 25% 是翻章带，中间 50% 点一下切工具栏。不做翻页动画 ——
分页要先测量渲染后的文本高度，而字号/行距/页边距都可调，就得反复重排；滚动在
移动端是原生手感，而且进度换算简单可靠。

中文正文首行缩进 `2em` 加 `text-align: justify`，这是中文排版的默认期待。
