# 书架与发现

## 书架（`/web`）

C 端首页。两种视图切换，状态存 `localStorage`。

```
┌─────────────────────────────┐
│ 书架            [搜索][视图] │  TopBar
├─────────────────────────────┤
│ [最近阅读 ▾]          12 本  │  工具栏
├─────────────────────────────┤
│ ┌────┐ ┌────┐ ┌────┐        │
│ │封面│ │封面│ │封面│        │  网格视图
│ └────┘ └────┘ └────┘        │  auto-fill minmax(100px, 1fr)
│ 书名   书名   书名           │
│ 读到第7章 未开始 读到第3章    │
├─────────────────────────────┤
│ 书架 发现 订阅 我的          │  TabBar
└─────────────────────────────┘
```

网格用 `repeat(auto-fill, minmax(100px, 1fr))` 而不是写断点：小屏自然两三列、
大屏自动变多列。

**点一本书 = 续读。** 有进度直接跳正文的那一章，没有才进详情页。多一步选择对
「接着读」这个最高频动作是纯损耗。

列表视图把「读到第 N 章 · 章节名」完整显示出来，网格视图只有「读到第 N 章」——
网格里一行放不下章节名，截断了反而更难认。

## 发现（`/web/search`）

```
┌─────────────────────────────┐
│ 发现                         │
├─────────────────────────────┤
│ [🔍 搜书名或作者    ] [搜索] │
├─────────────────────────────┤
│ 最近搜索              清空   │  未搜索时显示
│ (剑来) (雪中悍刀行) (...)    │
├─────────────────────────────┤
│ 7/10 个源有响应，命中 23 本   │  源统计
│ · 2 个源需要 JS，当前不支持   │
├─────────────────────────────┤
│ ┌──┐ 剑来                    │
│ │封│ 烽火戏诸侯  5 个来源     │
│ └──┘ 最新：第 1203 章         │
├─────────────────────────────┤
│         [加载更多]           │
└─────────────────────────────┘
```

源统计那一行是这页的关键，理由见
[产品功能清单的「为什么 B2 不是可选项」](../../../product/reader-client/002-feature-list.md)。

输入框带 `enterkeyhint="search"`，手机软键盘的回车键会显示成「搜索」而不是换行。
