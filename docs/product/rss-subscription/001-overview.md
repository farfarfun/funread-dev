# 订阅源产品说明

订阅源是阅读端除小说之外的第二类内容。入口在 `/web/rss`，和小说共用同一套阅读
设置（字号、行距、配色）。

## 一句话概括

用户可以订阅归档里的 Legado RSS 源，也可以自己贴一个标准 feed 地址；两者在界面上
是同一个「我的订阅」列表里的两行，读文章的体验完全一致。
